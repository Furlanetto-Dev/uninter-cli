# Saying that there is nothing to show

## TL;DR
- `cli/components/hint.py` keeps `Hint` and gains `show_or(widget, message)`: the message and the widget it replaces are shown and hidden together.
- The six empty states become its callers: matérias, atividades, trabalhos, the never-synced matéria, the debug column's `—` and the prova's `Nada foi enviado ao AVA`.
- `pages/materias/page.py` stops setting `display` on `AtividadeTree`, `TrabalhoTable` and `AtividadeHeader` in four places.
- The colour of each message is [0017](../pending/0017-interface-meanings.md)'s subject; this spec only settles where it is shown.

`Hint` exists and two of the six use it. The others each invented their own arrangement: a `Static` beside a table with both `display` flags flipped by hand, or a sentence appended to the end of a summary. Part of [0016](../done/0016-cli-components.md).

## Observed behaviour
- `pages/materias/page.py` pairs a `Hint` with `table.display = bool(rows)` in `_show_atividades` and `_show_trabalhos`, and repeats the pair for `AtividadeHeader`; `reload_materias` sets four `display` flags in a row for the no-matérias case.
- `StoredColumn` composes a second `Static` holding a dim `—` and flips its `display` against the table's, which is the same pair written a third way.
- `ProvaPage.summary` glues its warning to the end of the rendered text, so the empty state is part of a string.
- The six messages live in five modules: `NO_MATERIAS`, `NEVER_SYNCED`, `NO_ATIVIDADES`, `NO_TRABALHOS`, `MISSING`, `NOTHING_SENT`.

## Decisions

### The hint and the widget it replaces are one call
`show_or(table, message)` shows one or the other, never both and never neither. Four call sites setting two `display` flags each is four chances to show an empty table under a message saying it is empty.

### The messages stay where they are
`NO_ATIVIDADES` belongs next to the tree that has none — it says something about atividades, not about hints. The component owns the shape and the toggling; the wording stays with the screen that knows what is missing.

### The prova's warning becomes a hint too
It is the same thing: a sentence where content would be. Keeping it inside the summary string is what made it the one empty state nobody could restyle.

## Rejected
- **A `Hint` that queries its own sibling.** The caller knows which widget the message stands in for; making the hint search for it hides that in a query.
- **Moving every message into one `messages.py`.** It would group sentences by nothing but their shape, and put the wording a screen away from the screen.

## What execution corrected
- The signature is `show_or(message, *widgets)`, not `show_or(widget, message)`: the atividades hint stands in for the tree *and* its header, and no caller reads better with the widget first.
- The prova's warning needed `#prova-body Hint { margin-top: 1 }` to keep the blank line the concatenated string used to carry. Verified against the finished prova, which the six-view smoke does not reach.
